# Books Tools ブログを公開しました

Books Tools にブログ機能を追加しました。

- ホーム画面とヘッダーからブログへ遷移できます
- `content/blog/*.mdx` に MDX で記事を追加できます
- GitHub Actions から手動で記事テンプレートを作成できます
